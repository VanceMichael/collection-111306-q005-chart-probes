# 本地资料源约定

界面仅公开正常图例、鼠标提示和缩放按钮；页面内数据不是采集接口。提示可能延迟，包含系列身份、观测区间和交互代次。曲线含真实缺值，不应按绘制路径推断数据点。

## 通用控制

`GET /api/snapshot` 查看当前原始源状态；`POST /api/action` 接收 JSON 对象 `{"action":"动作名"}`。可用动作：reset、zoom。控制只改变模拟源，不代表接收器已经处理了变化。

所有资料均由本项目构造，包含的机构、设备、会话和文件仅供本地使用，不访问真实账号。浏览器操作应通过正常可见界面；测试用源控制接口不是业务采集捷径。

## 提示层语义（采集器依赖）

提示层是页面唯一公开的读数通道，采集器只解析它的文本：

- `series` 是系列身份，`label` 只是显示文本；同名 `label` 的不同 `series` 必须分开。
- `range` 是提示层实际覆盖的横坐标区间（0–1 的归一化位置）。同一区间内移动鼠标会得到同一组 `range`/`x`/`value`，不应按鼠标位置拆成多个点。
- `value` 为 `null` 表示断点，覆盖区间仍由 `range` 给出。
- `unit` 是该观测的单位。
- `revision` 是交互代次，图例切换与缩放都会推进；`view` 是当前视口。
- 提示可能延迟返回；采集器只在提示自报代次与本次交互一致时接受它。

精度信息只存在于提示层原文的 token 中（如 `x` 显示为 `10` 还是 `10.0`），采集器按原文计算小数位数。

## 来源证据

源端请求记录只用于核查服务行为，接收器自身的审计、状态和输出需由扩展功能负责。源端重启会恢复默认资料，但本地接收文件不会自动清空。
