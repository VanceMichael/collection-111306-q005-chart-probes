# 交互曲线提示层的有界观测采集

工艺工程师每周要抄供应商网页上的几条测试曲线，对方只允许从交互图查看，不提供导出。这里保存现有资料预览工具和本地供方模拟服务，便于离线开发和复查领取行为。

## 当前能力

`npm run demo` 启动本地资料源，用真实浏览器在交互图上执行一次**有界观测采集**：只用正常的鼠标悬停、图例点击和缩放按钮读取提示层，不调用页面未公开的数据接口。采集结果写入 `var/captures.json`，并打印本次观测、未知区间和预算去向。它仍不是批量接收器：每次运行采集一次，预算耗尽或精度无法再细化即停止。

采集规则：

- 每条观测记录提示层原文证据：系列身份、横坐标、读数、单位、页面报告的比例区间与精度；区间归并（一段横坐标显示同一组值）按原样归并记录，空值断点保留为空值，不插值补成没见过的点。
- 图例开关与缩放都有交互代次，迟到的提示按代次丢弃并留痕，不与新状态混用；系列重名时不按标签合并，按提示层报告的系列身份分别记录。
- 探测操作有总预算（图例点击、鼠标探测、缩放点击各计 1 次），缩放后分组精度无变化即停止缩放，且缩放次数有上限，不为追求完整无限缩放；未覆盖的区间逐条列出并说明原因。

`npm run preview` 保留原有单次预览行为。`src/domain.mjs` 保留已有领域预览函数；`src/store.mjs` 提供带完整性校验的单进程顺序接收文件，不是跨进程事务数据库。

## 运行

容器内固定 Playwright 1.56.1 与匹配的 Chromium。浏览器只访问本进程启动的回环资料源，不需要访问外部门户。

```sh
npm ci
npx playwright install chromium
npm run build
npm test
npm run demo
```

推荐使用固定镜像构建，首次构建会安装锁文件中的依赖；运行时不需联网。

```sh
docker build -t plant-chart-probes .
docker run --rm --network none --ipc=host plant-chart-probes npm test
docker run --rm --network none --ipc=host plant-chart-probes npm run demo
```

开发时 `npm start` 打印本地源地址；设置 `PORT` 可指定监听端口，未设置时自动分配回环端口。浏览器页面或 HTTP 接口可直接查看。`CAPTURE_PATH` 可改变接收文件路径。重复运行预览追加记录；删除 `var` 可从空接收状态开始。

## 模块

- `src/source.mjs`：该业务的本地资料源与演示控制，独立于待扩展的接收行为。
- `src/domain.mjs`：现有原始资料预览和领域数据结构。
- `src/preview.mjs`：读取、预览及持久化的一次运行入口（`npm run preview`）。
- `src/collector.mjs`：曲线观测采集器，只用页面正常操作读取提示层，管理预算、迟到提示丢弃与缺口解释。
- `src/collect.mjs`：采集运行入口（`npm run demo`），可用 `COLLECT_BUDGET` 调整总预算。
- `fixtures/source.json` 与 `fixtures/controls.json`：本地供方资料及可切换情形。
- `docs/source.md`：接口和来源约定。
- `test`：现有预览、源端特殊情形、接收文件完整性测试。

## 业务核对

以下情况由 `test/collector.test.mjs` 在真实浏览器中独立核对，而不仅是源端能够制造这些情况：

- 相同标签的不同系列：按提示层报告的系列身份分别记录，不按标签合并。
- 断点区间保持未知：空值断点记为观测到的断点，组间未覆盖区间保持未知，不插值。
- 非线性横轴：比例区间按操作员配置的坐标轴（线性/对数）换算，取值形态提示来自观测证据。
- 视口切换后迟到提示：按交互代次与视口代次丢弃并留痕，不混入新状态。
- 预算耗尽能够停止且解释缺口：操作总数不超预算，未探测区间逐条标注原因。

其余测试验证现有工具与源端行为。采集器在独立模块扩展，保留原有预览调用；禁止把源端模拟器改成替接收器完成核对。

## 短时操作演示

从空 `var` 运行 `npm run demo`，展示本次真实采集：观测到的系列与断点、仍未知的区间及原因、预算花费去向，以及接收文件路径；再运行 `npm test` 查看采集器业务核对、本地源边界与接收文件检查。固定环境中的这两步应在 90 秒内完成。演示每次重新采集，不回放旧日志，不以源端控制操作代替接收结果。
